# Prospector Drone 0.3.20

Release prepared, edited, and maintained by **Darkethereal**.

## Highlights

- Autonomous mining for Wood, Copper, Glass, and Iron.
- Persistent drone cargo and station storage integration.
- Upgradeable flight speed, mining speed, cargo capacity, and range.
- Visible docking, improved ground clearance, hover bobbing, and post-mining leveling.
- Storage protection prevents incompatible resource selection and collection.
- SDModKit dependency declared for automatic dependency handling.

## Installation

Install through Stellar Mod Manager. SDModKit is required and should be installed automatically when dependency handling is available.
